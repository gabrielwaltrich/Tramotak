# Tramotak 0.9.0 — pré-lançamento (beta)

Esta é uma **versão de teste** para a 1.0. Ela aparece nas Releases como pré-lançamento e **não** é oferecida pela
atualização automática de quem usa a versão estável: para testar, baixe os arquivos abaixo. Seus dados são migrados
sozinhos, mas **faça um backup antes** (Configurações → Dados e backup).

Se encontrar um problema, use **Configurações → Sobre → Relatar problema** e abra o formulário no GitHub.

## O que muda desde a 0.7.3

### Acessibilidade
- Tela por tela, com verificação automática (axe-core, WCAG 2.1 AA) incluída nos testes do projeto.
- **Contraste** corrigido em todos os 5 temas e nas 8 cores de destaque (texto suave e cores de destaque ficaram
  mais legíveis; o azul, o roxo, o âmbar e outros tons de destaque mudaram um pouco).
- Nomes de botões coerentes com o que aparece na tela (busca, Pomodoro, velocidade do vídeo), barra de progresso do
  curso anunciada como tal, link de código-fonte sublinhado e capa dos cursos fora da ordem do teclado (o título
  já abre o curso).

### Distribuição
- Dentro do **Flatpak** a atualização própria do app fica desligada (quem atualiza é o Flathub).
- Rascunhos para o **Flathub**, o **winget** e a assinatura do instalador do Windows pelo **SignPath** em `packaging/`.

### Documentação
- **Guia de uso** com todas as telas (`docs/GUIA-DE-USO.md`).

## Instalação

| Sistema | Arquivo |
|---|---|
| Windows | `Tramotak-0.9.0-setup.exe` (instalador) ou `Tramotak-0.9.0-portable.exe` |
| Linux | `Tramotak-0.9.0-linux-x86_64.AppImage` ou `Tramotak-0.9.0-linux-amd64.deb` |

Os instaladores **ainda não são assinados**:

- **Windows:** no aviso do SmartScreen, clique em **Mais informações → Executar assim mesmo**.
- **Linux:** no AppImage, dê permissão de execução (`chmod +x`). No Ubuntu 24.04+, prefira o `.deb` ou rode o AppImage com `--no-sandbox`.

Confira a integridade dos arquivos com o `SHA256SUMS.txt` anexado (`sha256sum -c SHA256SUMS.txt`).

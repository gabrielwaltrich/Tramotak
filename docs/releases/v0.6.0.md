# Tramotak 0.6.0 — plano de estudos e FSRS

## Novidades

### Plano de estudos
- Na página do curso, **"Criar plano de estudos"**. Há dois modos:
  - **terminar até uma data**: o tempo das aulas é dividido igualmente entre os dias de estudo, na ordem do curso;
  - **minutos por dia**: cada dia recebe aulas até o tempo escolhido.
- Escolha os dias da semana, a velocidade em que assiste aos vídeos e o dia de início.
- Antes de salvar, uma prévia mostra:
  - quantas aulas e horas faltam;
  - o tempo por dia;
  - a data de término;
  - um aviso se passar de 4 h por dia.
- Cada dia vira uma tarefa no **Planner** com as aulas daquele dia. A tarefa se conclui sozinha quando todas as aulas forem concluídas, inclusive se você adiantar.
- O cartão do plano, no curso e no Planner, mostra as aulas de hoje, a data de término, as aulas atrasadas e uma previsão pelo seu ritmo real dos últimos 14 dias.
- **Replanejar:** se sobrarem aulas de dias que passaram, o app redistribui tudo a partir de hoje, sozinho (ao abrir e na virada do dia) ou pelo botão. No modo "data", a meta é mantida; no modo "minutos por dia", o término é adiado.
- No quadro do Planner, os dias futuros dos planos ficam só no Calendário, para cursos grandes não lotarem a coluna "A fazer".

### Flashcards com FSRS
- A repetição espaçada agora usa o **FSRS**, o algoritmo do Anki atual. Ele estima, para cada carta, quanto tempo você lembra dela e quão difícil ela é, e marca a revisão para quando a chance de lembrar cair à retenção escolhida. O resultado são menos revisões para lembrar o mesmo tanto.
- Cartas que você já estudava passam para o FSRS ao abrir o app, calculadas pelo histórico de respostas. As datas de revisão já marcadas não mudam.
- **Opções por baralho** (Editar baralho → Opções de estudo):
  - retenção desejada (70–97%);
  - novas e revisões por dia;
  - etapas de aprendizado e ao errar;
  - intervalo máximo.
- Na lista de cartas, passe o mouse no estado da carta para ver a chance de lembrar hoje.
- Pacotes `.tramotak` levam as opções do baralho e a memória das cartas.

## Instalação

| Sistema | Arquivo |
|---|---|
| Windows | `Tramotak-0.6.0-setup.exe` (instalador) ou `Tramotak-0.6.0-portable.exe` |
| macOS Apple Silicon | `Tramotak-0.6.0-arm64.dmg` |
| macOS Intel | `Tramotak-0.6.0-x64.dmg` |
| Linux | `Tramotak-0.6.0-linux-x86_64.AppImage` ou `Tramotak-0.6.0-linux-amd64.deb` |

Quem está na 0.5.0 recebe esta versão pela atualização automática (no `.deb`, o sistema pede a sua senha). O banco é migrado sozinho. Por precaução, antes de atualizar, copie a pasta de dados (Configurações → Dados → Abrir pasta).

Os instaladores **ainda não são assinados**:

- **Windows:** no aviso do SmartScreen, clique em **Mais informações → Executar assim mesmo**.
- **macOS:** na primeira vez, clique com o botão direito no app → **Abrir**. Se o macOS bloquear, vá em **Ajustes do Sistema → Privacidade e Segurança → Abrir Assim Mesmo**.
- **Linux:** no AppImage, dê permissão de execução (`chmod +x`). No Ubuntu 24.04+, prefira o `.deb` ou rode o AppImage com `--no-sandbox`.

Confira a integridade dos arquivos com o `SHA256SUMS.txt` anexado (`sha256sum -c SHA256SUMS.txt`).

## Observações

- O FSRS usa os parâmetros padrão do Anki. Ajustá-los ao seu próprio histórico fica para uma próxima versão.
- Mudar a retenção desejada vale a partir da próxima resposta de cada carta; as datas já marcadas não são refeitas.
- Esta é uma versão 0.x: o formato do banco pode evoluir, mas as atualizações migram os dados automaticamente.

# Tramotak 0.4.2 — aparência do seu jeito e busca no topo

## Novidades

### Aparência
Em **Configurações → Aparência**:
- **Estilos prontos**, que mudam tudo com um clique:
  - **Tramotak**: o padrão, escuro com o azul do ícone;
  - **Foco**: preto total, compacto e sem animações;
  - **Noturno azul**;
  - **Leitura**: fundo de papel, letra com serifa e tudo maior;
  - **Claro**.
- **Ajustes individuais**:
  - tema: Grafite, Meia-noite, Azul-marinho, Claro, Papel ou o do sistema;
  - **8 cores de destaque**: azul, roxo, ciano, verde, âmbar, laranja, rosa e grafite;
  - tamanho da interface (compacta, padrão, grande);
  - cantos (retos, arredondados, bem redondos);
  - fonte com serifa para leitura;
  - reduzir animações.
- O azul do ícone passou a ser a cor padrão. Quem preferir o roxo antigo pode escolhê-lo.
- O texto sobre a cor de destaque fica branco ou escuro automaticamente, para ficar sempre legível.

### Busca no topo
- A busca virou uma **barra de pesquisa no alto de todas as telas**. Clique nela ou comece a digitar com ela selecionada; `Ctrl+K` (`⌘K` no Mac) continua funcionando.

## Instalação

| Sistema | Arquivo |
|---|---|
| Windows | `Tramotak-0.4.2-setup.exe` (instalador) ou `Tramotak-0.4.2-portable.exe` |
| macOS Apple Silicon | `Tramotak-0.4.2-arm64.dmg` |
| macOS Intel | `Tramotak-0.4.2-x64.dmg` |
| Linux | `Tramotak-0.4.2-linux-x86_64.AppImage` ou `Tramotak-0.4.2-linux-amd64.deb` |

Quem já usa uma versão anterior pode instalar por cima: o banco é migrado automaticamente. Por precaução, antes de atualizar, copie a pasta de dados (Configurações → Dados → Abrir pasta).

Os instaladores **ainda não são assinados**:

- **Windows:** no aviso do SmartScreen, clique em **Mais informações → Executar assim mesmo**.
- **macOS:** na primeira vez, clique com o botão direito no app → **Abrir**. Se o macOS bloquear, vá em **Ajustes do Sistema → Privacidade e Segurança → Abrir Assim Mesmo**.
- **Linux:** no AppImage, dê permissão de execução (`chmod +x`). No Ubuntu 24.04+, prefira o `.deb` ou rode o AppImage com `--no-sandbox`.

Confira a integridade dos arquivos com o `SHA256SUMS.txt` anexado (`sha256sum -c SHA256SUMS.txt`).

## Observações

- No plano gratuito do Gemini, o Google pode usar o conteúdo enviado para melhorar os produtos dele. Alguns modelos gratuitos do OpenRouter também podem guardar o que é enviado. Para material sigiloso, use um modelo local.
- O Tramotak inclui o FFmpeg (licença GPL) como programa separado; a licença está em Configurações → Sobre.
- Esta é uma versão 0.x: o formato do banco pode evoluir, mas as atualizações migram os dados automaticamente.

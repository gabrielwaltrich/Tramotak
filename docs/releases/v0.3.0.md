# Tramotak 0.3.0 — IA (dá para usar de graça), backup e pacotes de estudo

## Novidades

### Inteligência artificial
Gere **flashcards, questões, resumos e mapas mentais** a partir do seu material e revise tudo antes de salvar. O material pode vir da transcrição, da legenda, dos anexos de texto e das anotações de uma aula, de uma página de caderno ou de um texto colado.

- **Gemini grátis:** crie uma chave no Google AI Studio com a sua conta Google pessoal (sem cartão) e cole no app; o passo a passo está na tela.
- **OpenRouter:** botão **Entrar com OpenRouter** (login pelo navegador). Use `openrouter/free`, que escolhe sozinho um modelo gratuito, ou modelos pagos com créditos da sua conta, incluindo Claude e GPT.
- **Modelos locais (Ollama):** instale modelos leves pelo próprio app (Llama 3.2, Qwen 2.5/3, Gemma 3), com barra de progresso. Funciona sem internet e nada sai do computador.
- **Claude (chave do Claude Console)** e **qualquer servidor compatível com a OpenAI** (OpenAI, LM Studio, vLLM…).
- Botões **Gerar com IA** no player, no baralho, no banco de questões e no caderno.
- As cartas ficam ligadas à aula, o resumo vira página de caderno e o mapa nasce com a aula anexada.
- As chaves ficam cifradas pelo cofre do sistema. O material só é enviado quando você clica em gerar.

> A assinatura pessoal do Claude (Free/Pro/Max) não pode ser usada em outros apps: é uma regra da Anthropic. Para usar o Claude, crie uma chave de API ou use o OpenRouter.

### Backup e outro computador
- **Backup completo** num arquivo `.db`, manual ou **automático diário** (guarda os 7 mais recentes). O backup não leva os vídeos nem as chaves de API.
- **Restaurar** a partir de um arquivo ou da lista de backups. O app mostra o que tem no backup, guarda o estado atual antes de trocar e reinicia. No AppImage e no `.exe` portátil, o app fecha e a restauração é concluída quando você abre de novo.
- **Trocar pasta…** no menu do curso: depois de mover o curso ou restaurar em outro computador, aponte para a nova pasta e mantenha o progresso e as anotações.

### Pacotes de estudo (`.tramotak`)
- **Exportar:** baralhos (com ou sem o agendamento), bancos de questões com simulados, cadernos, mapas mentais e as anotações, transcrições e progresso dos cursos.
- **Importar:** cada curso do pacote é ligado a um curso seu (o app sugere qual). Tudo entra como itens novos e nada é apagado.

### Outras melhorias
- Diálogos com nome acessível para leitores de tela.
- O caderno abre direto na página recém-criada.

## Instalação

| Sistema | Arquivo |
|---|---|
| Windows | `Tramotak-0.3.0-setup.exe` (instalador) ou `Tramotak-0.3.0-portable.exe` |
| macOS Apple Silicon | `Tramotak-0.3.0-arm64.dmg` |
| macOS Intel | `Tramotak-0.3.0-x64.dmg` |
| Linux | `Tramotak-0.3.0-linux-x86_64.AppImage` ou `Tramotak-0.3.0-linux-amd64.deb` |

Quem já usa a 0.2.0 pode instalar por cima: o banco é migrado automaticamente. Por precaução, antes de atualizar, copie a pasta de dados (Configurações → Dados → Abrir pasta).

Os instaladores **ainda não são assinados**:

- **Windows:** no aviso do SmartScreen, clique em **Mais informações → Executar assim mesmo**.
- **macOS:** na primeira vez, clique com o botão direito no app → **Abrir**. Se o macOS bloquear, vá em **Ajustes do Sistema → Privacidade e Segurança → Abrir Assim Mesmo**.
- **Linux:** no AppImage, dê permissão de execução (`chmod +x`). No Ubuntu 24.04+, prefira o `.deb` ou rode o AppImage com `--no-sandbox`.

Confira a integridade dos arquivos com o `SHA256SUMS.txt` anexado (`sha256sum -c SHA256SUMS.txt`).

## Observações

- No plano gratuito do Gemini, o Google pode usar o conteúdo enviado para melhorar os produtos dele. Alguns modelos gratuitos do OpenRouter também podem guardar o que é enviado. Para material sigiloso, use um modelo local.
- O Tramotak inclui o FFmpeg (licença GPL) como programa separado; a licença está em Configurações → Sobre.
- Esta é uma versão 0.x: o formato do banco pode evoluir, mas as atualizações migram os dados automaticamente.

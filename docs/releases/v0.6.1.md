# Tramotak 0.6.1 — todas as anotações num lugar só

## Novidades

### Página "Anotações"
- Nova aba **Anotações** na barra lateral, com o que você anotou em todos os cursos, sem precisar abrir aula por aula.
- As notas ficam agrupadas por curso, módulo e aula, ou com as mais recentes primeiro.
- Busca nas anotações e filtro por curso.
- O horário de cada nota abre o vídeo naquele ponto.
- Dá para editar, excluir ou transformar em flashcard ali mesmo.
- Selecione notas, uma aula inteira ou tudo o que está na tela para:
  - enviar para um caderno;
  - exportar em Markdown (`.md`).

### Anotações nos cadernos
- Envie anotações para um caderno novo ou existente, numa página nova ou no fim de uma página.
- Cada aula vira um atalho para o vídeo, seguido das notas. Os **horários são links que abrem o vídeo no segundo certo**, e o texto continua editável como qualquer texto do caderno.
- No player, cada nota tem o botão "Enviar para caderno". O painel de anotações ganhou "Todas as anotações do curso" e "Enviar as desta aula para um caderno".

### Ajustes
- Anotações mostram fórmulas (`$...$`) também no player.
- Títulos de aula muito longos, sem espaços, não criam mais rolagem lateral no player.

## Instalação

| Sistema | Arquivo |
|---|---|
| Windows | `Tramotak-0.6.1-setup.exe` (instalador) ou `Tramotak-0.6.1-portable.exe` |
| Linux | `Tramotak-0.6.1-linux-x86_64.AppImage` ou `Tramotak-0.6.1-linux-amd64.deb` |

Quem está na 0.5.0 ou na 0.6.0 recebe esta versão pela atualização automática (no `.deb`, o sistema pede a sua senha).

Os instaladores **ainda não são assinados**:

- **Windows:** no aviso do SmartScreen, clique em **Mais informações → Executar assim mesmo**.
- **Linux:** no AppImage, dê permissão de execução (`chmod +x`). No Ubuntu 24.04+, prefira o `.deb` ou rode o AppImage com `--no-sandbox`.

Confira a integridade dos arquivos com o `SHA256SUMS.txt` anexado (`sha256sum -c SHA256SUMS.txt`).

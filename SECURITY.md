# Segurança

## Versões que recebem correção

Só a versão mais recente publicada nas [Releases](https://github.com/gabrielwaltrich/Tramotak/releases/latest).
O app se atualiza sozinho (exceto o `.exe` portátil); quem estiver numa versão antiga deve atualizar primeiro.

## Como relatar uma falha

**Não abra uma issue pública.** Use o aviso privado do GitHub:
[Security → Report a vulnerability](https://github.com/gabrielwaltrich/Tramotak/security/advisories/new).

Conte o que dá para fazer com a falha, a versão e o sistema, e os passos para reproduzir. A resposta inicial vem em
até 7 dias. Depois de corrigida, a falha é descrita nas notas da versão, com crédito a quem relatou (se quiser).

## O que conta como falha

Por exemplo: a interface conseguir ler arquivos fora das pastas dos cursos e da pasta do app, as chaves de API
saírem do cofre do sistema ou irem parar num backup, conteúdo de um curso (Markdown, HTML, PDF, legenda) conseguir
rodar código, ou a atualização automática aceitar um instalador que não veio das Releases.
